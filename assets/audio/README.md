# Audio

Every file here is original: generated by `tools/generate_audio.py` (pure Python, no
dependencies, deterministic). There is no third-party audio, so nothing to attribute and no
license terms beyond the repository's own. Re-run the script and commit the WAVs to change them.

| File | Use |
| --- | --- |
| `music_ambient.wav` | 32 s seamless underwater ambient loop for the home screen (pads, sparse bubble plucks) |
| `music_<map id>.wav` | 24 s seamless loop per map (zigzag, pachinko, wreck, whirlpool, jelly, abyss, vents, cave, kraken, gravity, tide, fork, city, washer, whale, flush, switchback, garden, pinball, fault, riptide), defined in `tools/music_themes.py`; the `Sound` autoload crossfades to it when a map loads |
| `ambience_<map id>.wav` | 8 s seamless 8 kHz ambience bed per map (timber creaks, geyser rumble, sonar, shimmer...), defined in `tools/map_audio.py`; plays on the Ambience bus under the music |
| `jingle_<map id>.wav` | 2.8 s win jingle per map in that map's key, played at the podium instead of `sfx_win.wav` |
| `sfx_join.wav` | a viewer joins the lobby |
| `sfx_tick.wav` | countdown tick |
| `sfx_go.wav` | race start |
| `sfx_boost.wav` | `#boost` applied |
| `sfx_curse.wav` | `#curse` applied |
| `sfx_splash.wav` | a fish crosses the finish |
| `sfx_win.wav` | podium with a finished winner |
| `sfx_meow.wav` | a viewer's fish meows (hidden chat command) |
| `sfx_kraken_grumble.wav` | the kraken grumbles with the warning before each strike on Kraken's Lair |
| `sfx_kraken_swoosh.wav` | the kraken's tentacles swoosh as a sweep begins |
| `sfx_rod_cast.wav` / `sfx_rod_catch.wav` | the streamer's rod drops with a splash / yanks a fish |
| `sfx_net_cast.wav` / `sfx_net_catch.wav` | the streamer's net is cast / tightens on a fish |
| `sfx_blast_cast.wav` / `sfx_blast_hit.wav` | the bubble blast charges and booms / scatters fish |

If you swap in downloaded sounds, only use CC0 (or similarly permissive) material and record the
source and license in this file.
